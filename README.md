# Witching Gadgets: Reforged

Неофициальный перенос Witching Gadgets 1.1.10 для Minecraft 1.21.1 / NeoForge. Механизмы, экипировка, исследования и русская локализация адаптированы к нашему Thaumcraft 4: Reforged.

Текущий выпуск: **1.1.10-port.16**.

## Для запуска

Нужны **Minecraft 1.21.1**, **Java 21** и **NeoForge 21.1**; общая сборка проверена на **21.1.264**.

- [Наш Thaumcraft 4: Reforged 1.1-bbtt.30-filter.1](https://github.com/yzs57phbts-web/thaumcraft-4-reforged-dop/releases/tag/1.21.1-bbtt.30-filter.1).
- [Curios API 9.5.1](https://www.curseforge.com/minecraft/mc-mods/curios/files/6529130) и [TerraBlender 4.1.0.1+ для NeoForge](https://www.curseforge.com/minecraft/mc-mods/terrablender-neoforge/files/6054947) — зависимости ядра T4. Для совместных проверок использовался TerraBlender 4.1.0.8.
- Twilight Forest и Thaumic Tinkerer необязательны. Требуются именно расширения нашей версии T4; один номер версии авторского порта совместимость не обеспечивает.

Скачайте JAR из [релиза 1.1.10-port.16](https://github.com/yzs57phbts-web/witching-gadgets-reforged/releases/tag/1.21.1-v1.1.10-port.16) и положите в `mods` вместе с зависимостями. В папке должна быть одна версия каждого мода.

## Добавили

Перенесённое содержимое, доступное в этой версии:

- Насос эссенции и связь через зеркала, преобразователь биомов и адская доменная печь.
- Ограночный стол, библиотека, прялка и работа с камнями.
- Самоцветная перчатка, её гнёзда, свойства и способности.
- Первозданная броня, плащи, бижутерия и магические сумки.
- Эфирные стены, маскировка, капсулы жидкостей и инструменты.

## Пофиксили

- Исправлены проверенные маршруты рецептов, расход ресурсов и сохранение устройств.
- Исправлены передача эссенции, запросы потребителей и согласование вывода насоса.
- Исправлены работа интерфейсов, камней, зачарований и особых свойств экипировки.
- В port.16 устранена зависимость тёмных значков исследований от номера сгенерированной Java-лямбды в T4.

## Адаптировали

- Перчатка и экипировка используют API жезлов и специальной защиты брони нашего T4.
- Бижутерия подключена к Curios, переключатели свойств имеют современные клавиши и сетевую синхронизацию.
- Содержимое и блокировки магических сумок сохраняются на сервере.

## Изменили

- Тело обработки затемнённых значков в port.16 сохранено; изменена только устойчивая точка подключения.
- Точное соответствие всем эффектам и графике Minecraft 1.7.10 не заявляется.

## Совместимость и проверки

Выпуск рассчитан на API нашей доработанной версии T4. Совместимость с чистым авторским T4 автоматически не предполагается.

Опубликованный JAR совпадает по SHA256 с выбранным установленным выпуском. Эта комбинация участвовала в проверке полной сборки: загрузка, настоящий Creative-мир, вкладка T4, прокрутка предметов и повтор после перезагрузки ресурсов. Это не означает полного прохождения всех механик каждого аддона. Подробности текущего выпуска и ограничения сохранены в исходниках/уведомлениях проекта; старые отчёты относятся к своим версиям.

## Сборка из исходников

Для компиляции сохранённых исходников нужен исторический API T4 **1.1-bbtt.11**: положите `thaumcraft-4-reforged-1.1-bbtt.11-1.21.1.jar` в `libs/` либо передайте его через `-PcoreJar`. Это исходная зависимость проекта. У базы 30 отсутствует `FortressArmorItem.protection`, поэтому она не заменяет этот JAR при компиляции. Саму зависимость в репозиторий не включаем.

На установленной базе 30 проверены загрузка и интерфейс Creative, но специальная защита унаследованной брони не подтверждена: API изменился. Полная совместимость всех механик брони с базой 30 не заявляется.

Curios и TerraBlender также положите в `libs/`. Можно задать `-PmodsDir=/путь/к/libs` и `-PcoreJar=/путь/к/T4.jar`.

```sh
./gradlew build
```

Старые GameTest-классы отделены от обычной сборки. `compileGameTestJava` компилирует их отдельно, `runGameTestServer` подключает их только в тестовом запуске. Вспомогательный игрок взят из исходников нашей базы T4.

Нужен JDK 21. Машинные пути разработчика, эталонные сторонние JAR, игровые миры и конфиги профиля в репозиторий не включены. Скомпилированный выпуск находится в GitHub Releases; `SHA256SUMS.txt` позволяет проверить скачивание.
